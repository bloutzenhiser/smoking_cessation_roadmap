# smoking_cessation_roadmap


This repository contains the planning and design work for a smoking cessation application.

The goal is to define what the application must do, what it must not do, how the user will interact with it, and how the underlying calculations should work before development begins.

The project will start with narrow functional requirements and a plain-English overview of those requirements.

The planned work includes:

* Functional requirements
* Cross-document review
* Requirement matrix
* Excel-based logic and calculations
* User input and screen design
* Initial reporting design
* MVP V1.0 review
* Future enhancements

The application is intended to use smoking periods rather than calendar days as its main unit of measurement.

Initial reporting will focus on:

* Cigarettes per hour
* Cost per hour

The first seven completed smoking periods will be used to gather baseline smoking data before the cessation plan begins.

The application should collect the data needed to support the user while avoiding unnecessary negative or discouraging information.

This repository is for planning and design. The application itself will be developed separately in the `smoking_cessation` repository.
